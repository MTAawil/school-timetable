# Start Here

This package is a build blueprint for a school weekly timetable generator.

## How to use it with Codex

1. Create a new empty Git repository.
2. Copy `AGENTS.md` to the repository root.
3. Copy the `docs/` directory into the repository.
4. Open the repository in Codex.
5. Paste Task 0 from `docs/CODEX_BUILD_TASKS.md`.
6. Review the plan and diff.
7. Run Tasks 1–10 sequentially, reviewing and testing after every task.

Do not begin by asking Codex to “build the full app.” The staged tasks create review points and prevent the solver, database, and interface from drifting apart.

## Important product decision

The MVP is for one school. Prove feasibility checking, timetable generation, manual editing, locks, and regeneration before adding SaaS features.
